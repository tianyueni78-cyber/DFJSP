# 问题定义

## 第一阶段研究边界

第一阶段假设故障事件已经由外部设备、PLC、MES 或人工报告检测完成。本项目只研究收到故障事件后的动态重调度，不研究传感器故障诊断。

## 初始故障假设

1. 每个实验场景只发生一次单机器故障。
2. 故障开始时刻和维修时长已知。
3. 故障期间，该机器不可执行新工序。
4. 故障前已经完成的任务保持不变。
5. 尚未开始的工序允许重新选择候选机器。
6. 故障时正在加工的工序暂定为中断并重新加工。
7. AGV 不发生故障。
8. 暂不考虑新订单、订单取消和加工时间变化。

## 待确认问题

- 正在加工的工序是否必须从头加工？
- 故障机器修复后是否重新参与调度？
- 局部修复允许调整多大范围？
- 计划扰动采用开始时间变化、机器变化，还是加权组合计算？
