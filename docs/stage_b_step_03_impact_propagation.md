# 阶段 B 第 3 步：中断工序延迟影响传播

## 1. 目标

以第 2 步中断工序的新完成时间为根节点，将延迟沿以下两条路径传播：

1. 同一工件的下一道工序；
2. 原机器上的下一道工序。

之后继续沿每个受影响工序的工件后继和机器后继传播，直到没有新的时间
冲突，形成加工中故障的局部右移影响集合。

## 2. 与阶段 A 的区别

- 阶段 A 的传播根源是未开始工序与维修区间发生冲突；
- 阶段 B 的传播根源是中断工序恢复后的新完成时间；
- 中断工序本身不属于未开始工序集合，而是一个独立的虚拟根节点；
- 后续影响传播仍使用工件优先关系和机器队列关系。

## 3. 输出内容

- 中断根工序的原完成时间、新完成时间和延迟；
- 根工序的工件直接后继；
- 根工序的机器直接后继；
- 所有受影响未开始工序；
- 每道受影响工序的预计开始、预计结束和延迟；
- 影响原因：根工件后继、根机器后继、工件传播或机器传播；
- 未受影响的未开始工序集合。

## 4. 当前边界

本步只计算预计时间和影响集合：

- 不写回机器时间表；
- 不调整 AGV；
- 不执行完全重调度；
- 不改变原正常基线。
