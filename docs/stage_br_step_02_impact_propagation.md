# 阶段 B-R 第 2 步：从头加工延迟影响传播

## 目标

以完整重加工后的新完成时间为根节点，将延迟沿以下两条路径传播：

1. 同一工件的下一道工序；
2. 原机器上的下一道工序。

之后继续沿受影响工序的工件后继和机器后继传播，直到没有新的时间冲突。

## 与阶段 B 的公平对比

传播使用相同的正常基线、故障事件、工件优先关系和机器队列。唯一变化是
根工序完成时间：

- 阶段 B：修复后只加工剩余时间；
- 阶段 B-R：修复后重新加工完整原加工时间。

阶段 B-R 的根节点还记录故障前损失加工时间，但损失加工不贡献工序完成
进度。

## 实现方式

本步复用已经验证的阶段 B 工件/机器传播核心，不修改阶段 B 稳定代码。
阶段 B-R 适配器负责：

1. 校验从头加工恢复计划；
2. 将完整重加工完成时间传给传播核心；
3. 将输出重新标记为阶段 B-R；
4. 记录 `restart_from_zero`、`lost_processing_time` 和完整重加工时间；
5. 再次验证未开始工序集合完整划分。

## 输出

- 根工序原完成时间、新完成时间和延迟；
- 故障前损失加工时间；
- 根工件后继和根机器后继；
- 所有受影响未开始工序；
- 每道工序预计开始、预计结束、预计延迟和影响原因；
- 未受影响的未开始工序。

## 当前边界

- 不修改正常基线；
- 不写回机器时间表；
- 不调整 AGV；
- 不运行完全重调度搜索。
