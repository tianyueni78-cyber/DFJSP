# 阶段 C 第 17.1 步：最终审计场景矩阵

## 本步目标

第 17 步需要做场景矩阵、多随机种子与最终审计。为了避免把未实现能力直接
拿来跑，本步先建立场景矩阵配置，明确哪些场景已经可以运行，哪些仍是缺口。

本步不运行正式实验、不创建输出目录。

## 场景矩阵

| 场景 | 故障关系 | 中断规则 | 当前状态 | 是否可运行 |
|---|---|---|---|---|
| `C-S1` | 两台机器同时故障 | 保留进度、修复后续加工 | 已实现 | 是 |
| `C-S2` | 两台机器同时故障 | 从头加工 | 未实现 | 否 |
| `C-SEQ1` | 两次故障先后发生且维修不重叠 | 保留进度、修复后续加工 | 已实现 | 是 |
| `C-SEQ2` | 后一故障发生时前一机器仍在维修 | 保留进度、修复后续加工 | 待实现 | 否 |

## 多随机种子设置

- 随机种子：`[11, 22, 33, 42, 55]`
- 种群规模：`10`
- 最大代数：`100`
- 连续无改善停止：`10` 代
- 时间上限：`30` 秒

## 审计项

- 机器不重叠；
- 工件工序顺序；
- AGV 不重叠；
- 运输到达先于加工；
- 维修区间不加工；
- 中断承诺保留；
- 最终卸载完成；
- 能耗闭合；
- 组合选择有效。

- 测试：`tests/test_stage_c_final_audit_matrix_config.m`
